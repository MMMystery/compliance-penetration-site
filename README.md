## 核查依据

核查依据 5 大类 26 项官方公示渠道，覆盖登记注册、司法执行、监管执法、资质标准、知识产权与经营五个层面。
日常采集经授权商业数据服务聚合；进入结论的关键事实，在报告出具前回到原始公示渠道复核，并在证据清单中标注渠道与查询时点。

## 判定规则

规则库共 158 条，分三层：

- 通用层 48 条（一票否决 V / 高 A / 中 B / 低 C / 提示 D / 行业 T）
- 执法条线层 93 条（12 条市场监管执法条线，按监管暴露面挂载）
- 人物穿透层 17 条（身份穿透、时间线重建、关联网络、出资能力）

## 三态标注

报告中的每一条核查项只有三种状态：**有记录 / 确认无 / 未获取**。
「未获取」表示已查但该渠道未返回或无法确认，**不等同于无记录**，报告中不得混用。

## 免责声明

站内两份案例报告基于公开渠道可获取的信息整理，用于说明核查方法与报告形态。
报告内容为特定时点的风险提示，不构成对该主体的定性评价，也不构成投资、法律或商业决策的唯一依据。
如主体信息已发生变更，以官方公示渠道最新记录为准。
