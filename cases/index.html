02 — 对照

03 — 交付物

每个案例包含什么

不是一份结论，是一套可以拿去核、拿去辩、拿去归档的材料。

01

分节结构报告

摘要结论 / 主体信息 / 风险扫描 / 能力评估 / 行业专项 / 交叉验证 / 评级依据 / 数据源声明。

02

可解释的风险评级

触发了哪条规则、依据哪条数据、来自哪个来源，逐条列出。禁止只给一个「高风险」。

03

证据链与采集留痕

每条证据编号，记录来源、采集时间、原始返回片段，可逐条复核。

04

如实标注的数据缺口

未获取的维度明确写「未获取」并注明原因，不做任何推测性填充。

04 — 产出方式

案例不是手写的

是技能包跑出来的。同一个流程，换个企业名字，就是一份新报告——这正是它可以规模化的原因。

01

输入主体

企业全称或统一社会信用代码，存在同名时先做唯一性校验。

02

自动核查

十步流程跑完通用维度与行业专属维度，边采边记录来源与时间。

03

计算评级

按规则库计分并映射风险等级，输出准入建议与触发规则清单。

04

生成报告

输出 Markdown 与 HTML 双版本，含结论横幅与证据清单，可直接打印交付。
