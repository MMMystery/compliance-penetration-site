02 — 判定要点

什么情况下判高风险

判定规则把行业 know-how 固化下来，同一条数据在任何一次调查中给出同样的分值，不依赖经办人的经验。

CT-01

旅行社业务经营许可证缺失、过期或被吊销

不适格。无证经营旅游业务是文旅执法的第一红线。

CT-02

超范围经营（如无出境资质而组织出境游）

不适格。资质范围不覆盖业务需求，与检验检测行业的 T-02 同逻辑。

CT-03

旅游服务质量保证金未缴纳

+3 分。质保金是旅游行业赔付能力的底线，未缴即无兜底。

CT-04

质保金已被用于赔付且存在未补足记录

+2 分。说明已实际发生赔付，且当前保障能力处于缺口状态。

CT-05

因不合理低价游被处罚

+3 分。低价游必然靠购物返佣补亏，是后续强迫购物与服务质量崩塌的先行指标。

CT-06

强迫或变相强迫购物、擅自变更行程

+3 分。已发生实际侵害游客权益的行为。

CT-07

导游、领队无证上岗

+2 分。人员资质不合规，且通常伴随服务纠纷。

CT-08

A 级景区被取消等级或复核不达标

+2 分。等级是景区服务能力与管理水平的官方认定。

CT-09

高风险旅游项目未取得经营许可

不适格。涉及人身安全，无许可即不得经营。

CT-10

客运索道、观光车、大型游乐设施超期未检

不适格。特种设备条线（EQ-01）与行业规则同源，取不适格不再重复计分。

CT-11

旅游投诉量大 + 处理率低 + 事由集中

+2 分。三条必须同时成立。只满足"量大"不计分——大型机构的绝对投诉量天然高于小机构。

CT-12

分社、服务网点未备案即开展经营

+2 分。网点失控是责任主体不清的典型形态。

CT-13

质保金缴纳主体与签约主体不一致

+2 分。资质挂靠的结构性信号，责任与保障能力分离。

03 — 挂载的执法条线

本行业默认挂载的 8 条监管条线

行业规则之外，还要按主体的监管暴露面挂载执法条线。这 8 条是文旅方向的默认配置，出具报告时可增删。

条线代码为什么文旅要挂
行政处罚（通用）PEN全行业必挂：判断处罚性质、履行状态、是否从重
登记注册与信用监管REG全行业必挂：虚假登记、年报造假、异常名录
价格监管PRC门票、团费、自费项目是文旅最高频的执法风险点

  • CT-10 与 EQ-01 描述同一事实，取不适格，不叠加
  • CT-05 与 PRC-01（价格欺诈）同源时，按较高项计一次并在报告中说明
  • UC-03（虚假宣传）与 ADV-01（虚假广告）同源时同理，只计一次
04 — 风险形态图谱

文旅行业最常见的六种风险长什么样

这些不是理论推演，是行业里反复出现的形态。核查时按图索骥，比逐条翻报表快得多。

零负团费

地接社以低于成本价接团，靠购物返佣补亏。查法：比对线路报价与行程单中的购物点、自费项目数量。 出现即必然伴随强迫购物与服务质量问题，属于先行指标而非孤立问题。

资质挂靠

无资质者借用他人旅行社资质经营。查法：核对质保金缴纳主体、收款账户名称、合同签约主体三者是否一致。 三者分离即责任与保障能力脱钩。

网络低价游

直播、短视频平台销售旅游产品，宣传方与实际服务提供方不是同一主体。查法：看平台内经营者身份公示是否完整、 收款方是否为宣传主体。

景区高风险项目

漂流、玻璃栈道、索道分属不同许可体系，且特种设备还要单独看检验有效期。查法：许可与检验两套记录分别核， 只查一套必然漏。

预付式旅游卡

年卡、套票、储值卡叠加文旅与预付卡双重风险。查法：看是否有资金存管、备案，以及预付规模与主体资产是否匹配。

季节性主体循环

旺季新设、淡季注销，同一批人反复换主体。查法：走人物穿透 P-05 / P-06，看关联主体的存续周期与人员是否重合。

05 — 交付物

同一套事实，两份报告

内部决策要看到真实风险，商务推进要给对方留余地。两个目的冲突，所以用两个版本承载。

版本 A · 对内

内部尽调版

给决策人看，不修饰、不回避。用于内部风险评估与决策留痕。

  • 真实经营状况、投诉与处罚记录
  • 风险、缺陷、问题诊断，可含负面结论
  • 关联方穿透、股权变更轨迹、责任人身份
  • 触发的判定规则编号与计分明细
  • 证据编号、来源、取证时间留痕
版本 B · 对外

对外战略版

给合作方看，只用已核实数据，建设性表述。用于商务推进。

  • 只用已核实数据，不写入未获取项
  • 用"挑战 / 机遇"表述，不用"问题"
  • 不出现任何个人姓名，统一署顾问团队
  • 不提供第三方负面评价的原文引用
  • 建设性建议替代风险指责

配套交付：签约前核查清单

  • 背调做完、合同签下之前逐条对照，共九节，含"背调结论 → 合同条款"映射表
  • 命中 CT-03 / CT-04（质保金）→ 合同必须写入质保金补足与赔付条款
  • 命中 CT-13（挂靠信号）→ 必须要求主体一致性承诺与禁止转包条款
  • 命中 CT-05 / CT-06（低价游、强迫购物）→ 写入行程变更与购物点数量上限条款
  • 清单以 Word 交付，可直接打印勾选签字
06 — 案例位

给出主体名称，即可出具本行业报告

案例库当前公开的是检验检测行业的两个对照案例。文旅方向的维度、规则与条线配置已就绪，报告结构与公开案例完全一致。

本行业报告的固定结构（与公开案例一致）

  • 摘要与结论：主体、风险等级、核心发现、建议动作
  • 主体基本信息与资质核验（含许可证范围逐项比对）
  • 风险扫描：司法 / 行政 / 股权 / 税务四类
  • 行业专项核查：14 项专属核查项 + CT 系列判定
  • 挂载条线核查：8 条执法条线的命中明细
  • 人物穿透（可选加挂）：实控人、关联网络、时序模式
  • 交叉验证与数据冲突记录
  • 风险汇总与评级依据（分层计分：通用层 / 条线层 / 人物层）
  • 数据源说明与免责声明

需要的输入只有三项：企业全称（或统一社会信用代码）、所属行业场景（如"景区服务商准入"）、关注重点（如"重点看质保金与高风险项目许可"）。
